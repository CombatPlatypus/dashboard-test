# Registro de Alterações

Esta pasta guarda o histórico das manutenções no código do dashboard. Ao concluir uma manutenção e atualizar o contexto da área, adicione aqui uma entrada que descreva a alteração e aponte para os arquivos de contexto atualizados. O [AGENTS.md](../../AGENTS.md) descreve o fluxo completo.

Uma entrada pode usar um nome como `AAAA-MM-DD-descricao.md` e incluir a data, a função afetada, o que mudou e as verificações realizadas.
